# Corpus of Early Medieval Legal Texts

Репозиторий содержит программный фреймворк (скрипты и метаданные) для работы с корпусом раннесредневековых правовых текстов (V–XI вв.). 
Исходные тексты не распространяются по условиям авторских прав (см. раздел «Copyright»).

---

## С чего начать

Эти инструкции предполагают, что вы скачали репозиторий на свой компьютер. Если вы никогда не работали с Python и Git, выполните шаги по порядку.

### Шаг 0. Что нужно установить
1. **Python** (версия 3.8 или выше). Скачать с [python.org](https://www.python.org/downloads/). 
   > *При установке на Windows обязательно поставьте галочку **"Add Python to PATH"** внизу установщика.*
2. **Git**. Скачать с [git-scm.com](https://git-scm.com/).
3. **VS Code** (Visual Studio Code) — удобный редактор кода.

### Шаг 1. Скачать репозиторий и открыть его
Откройте терминал (Командную строку или PowerShell на Windows) и выполните:
```bash
git clone https://github.com/VLDK299/Corpus-of-Early-Medieval-Legal-Texts.git
cd Corpus-of-Early-Medieval-Legal-Texts
```
Откройте эту папку в VS Code (`Файл -> Открыть папку`).

### Шаг 2. Создать виртуальное окружение
Виртуальное окружение изолирует библиотеки проекта от остальной системы.
**Для Windows (PowerShell):**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```
*(Если PowerShell выдает ошибку про «политику выполнения», выполните команду: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*

**Для macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Шаг 3. Подготовить исходные тексты (Важно!)
Из-за авторских прав в репозитории **нет самих текстов памятников**. Скриптам нужно откуда-то их взять. Вам нужно добавить их вручную:

1. Создайте папку `raw` в корне проекта. 
   Положите туда файл `anglo_saxon_laws_DOE_2000.txt` (получить его можно в Dictionary of Old English).
2. Создайте папку `texts/continental/continental_raw`.
   Поместите туда `.txt` файлы континентальных правд (список изданий см. в `metadata.tsv`).

*(Папки `texts/anglo_saxon/`, `texts/continental/` и `word_forms/` создадутся автоматически при работе скриптов).*

### Шаг 4. Запустить сборку корпуса
Выполните эти команды по очереди в терминале:
```bash
# 1. Очистка исходников и создание файлов
python scripts/clean_doe.py
python scripts/clean_latin.py

# 2. Подсчет токенов и словоформ
python scripts/count_tokens.py
python scripts/word_forms.py
```

### Шаг 5. Проверить, что всё работает
```bash
python scripts/validate.py
```
Если в конце вы увидите `Результат: OK`, значит корпус собран правильно и готов к работе!

## Как делать запросы (Конкордансы и Коллокации)

Скрипты запускаются из терминала VS Code. **Важно:** вы должны находиться в корне проекта (там, где лежат `metadata.tsv` и папка `texts/`), а виртуальное окружение (`.venv`) должно быть активировано.

### Вариант А: Через панель VS Code Run and Debug
1. Откройте панель **Run and Debug** (иконка с треугольником и жуком слева).
2. Выберите нужную конфигурацию (например, «1. Конкорданс: wergeld (все варианты)»).
3. Нажмите **F5**. Результат появится во вкладке «Терминал».

Для нового слова: скопируйте блок в `.vscode/launch.json`, поменяйте `"name"` и `"args"`.

### Вариант Б: Через терминал вручную
Выполняйте команды прямо в терминале VS Code.

| Что нужно | Пример команды |
|---|---|
| **Конкретная словоформа** | `python scripts/concordance.py "wergeld" -i` |
| **Все орфографические варианты** | `python scripts/concordance.py -V wergeld -i` |
| **Паттерн (regex)** | `python scripts/concordance.py '^werg[ei]ld\w*$' -r -i` |
| **Фраза (2+ слова)** | `python scripts/concordance.py "si quis" -i -n 5000` |
| **Коллокации** | `python scripts/collocations.py -V cyning -i --min-ll 3.84` |

> **Regex в PowerShell — в одинарных кавычках.** В двойных `$` может быть съеден как переменная.

#### Полезные флаги
**Для конкорданса:**
- `-s continental` или `-s insular` — ограничить поиск подкорпусом.
- `-n 5000` — сколько строк показать (по умолчанию 100).
- `--tsv` и `-o result.tsv` — сохранить результат в таблицу для Excel.
- `-w 7` — ширина контекста в словах (по умолчанию 5).

**Для коллокаций:**
- `-n 5` — минимальная частота совместного вхождения (по умолчанию 3). *Внимание: у конкорданса флаг `-n` значит "сколько показать", а у коллокаций — "мин. частота".*
- `-t 50` — сколько коллокат показать (по умолчанию 100).
- `--min-ll 3.84` — отсечь статистически незначимые результаты (p < 0.05).
- `-m mi` или `-m tscore` — выбрать метрику (по умолчанию LL).

## Справка: Метрики коллокаций

`collocations.py` выводит таблицу со следующими колонками:

| Колонка | Что означает |
|---|---|
| `f_node` | Сколько раз встретился сам искомый узел во всем корпусе. |
| `N` | Общее число слов в подкорпусе. |
| `collocate` | Слово-сосед. |
| `f_obs` (O11) | Сколько раз сосед встретился рядом с узлом. |
| `f_exp` (E11) | Сколько раз он ожидался бы рядом случайно. |
| `ll` | Log-likelihood (основная метрика значимости). Больше 3.84 = p<0.05, больше 10.83 = p<0.001. |
| `mi` | Mutual Information (сила связи). Завышается на редких словах. |
| `tscore` | T-score. Хорош для поиска *типичных* (частых) связей. |
| `dice` | Dice coefficient. Симметричная мера близости (от 0 до 1). Удобна для сравнения разных узлов. |

**Если `LL = n/a`**: узел слишком частотный (`et`, `si`), математика не сходится. Используйте другие метрики (`-m mi`).

## Варианты орфографии (`-V`)

Варварская латынь и древнеанглийский дают много графических вариантов (`wergeld` / `wergild` / `weregild`). Вместо написания сложных регулярок используйте флаг `-V`.

Он берет базовое слово и ищет все его формы из файла `variants.tsv`. 
* `-V wergeld -i` найдет `wergeld`, `wergild`, `weregeld` и т.д.
* Если нужно добавить новое слово, откройте `variants.tsv` и допишите строку: `базовое_слово` и через запятую `варианты`.
* `exact=yes` — искать только точные совпадения (без падежных окончаний).
* `exact=no` — искать с любыми окончаниями (добавляет `\w*`).

## Структура проекта

- `raw/` — исходные файлы DOE (не коммитятся).
- `texts/` — очищенные тексты и ссылки на строки.
- `word_forms/` — частотные списки слов.
- `logs/` — отчеты (`tokens_report.tsv`, `word_forms_report.tsv`).
- `scripts/` — Python-скрипты.
- `metadata.tsv` — главный файл с атрибутами памятников.
- `inventory.tsv` — реестр памятников.
- `variants.tsv` — орфографические варианты.
- `.vscode/launch.json` — кнопки запуска в VS Code.
